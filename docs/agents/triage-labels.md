# Triage labels

Check the repository's current labels before assigning them. Choose existing
labels that describe the issue's status and who can act on it. These examples
are guidance rather than a required label set:

| Example label | Meaning |
| --- | --- |
| needs-triage | Maintainer evaluation needed |
| needs-info | Waiting for reporter information |
| ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | Human implementation required |
| wontfix | Will not be actioned |
