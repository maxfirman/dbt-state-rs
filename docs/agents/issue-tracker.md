# Issue tracker: GitHub

Issues and specs live in GitHub Issues for `maxfirman/dbt-state-rs`.
Use explicit `--repo maxfirman/dbt-state-rs` when using `gh` for issue operations.
For multiline bodies, write the text to a temporary file and use `--body-file`.

Record parent/child relationships and blockers in GitHub's native relationships
where supported, or use linked `Part of #<parent>` and `Blocked by: #<number>`
references in the issue body. When resolving an issue, record the outcome and
relevant implementation or validation links before closing it.
